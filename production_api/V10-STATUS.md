# Job Agent v10 — release evidence

Implemented: privacy-preserving CV text preview, explicit import confirmation, readiness checklist, dedicated import UI. Text is processed in memory; no raw CV is persisted by these endpoints. Keyword mentions are not evidence of proficiency.

Not implemented: automatic PDF/DOCX parsing, semantic AI analysis, external OAuth, live Stripe homologation, real PostgreSQL server test, cross-browser production test, production security certification.

Deployment gate: do not accept public payments until PostgreSQL migration, backups, billing and external E2E are verified.
